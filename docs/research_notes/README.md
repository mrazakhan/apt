# Research Notes

This directory is APT's research memory.

Each note should answer:

1. What does the source actually show?
2. Why might it matter for APT?
3. What should we carry forward?
4. What remains uncertain?
5. Which implementation or experiment should eventually test the idea?

## Convention

Use one Markdown file per paper or external system, for example `2609_32208_witness.md`.

## Important distinction

**Research notes** preserve evidence and exploratory ideas from external work.

**Architecture/tutorial documentation** records choices APT has actually adopted and should explain how those choices appear in code or experiments.
